# Структуры и алгоритмы обработки данных на языке C++

На данный момент в репозитории представлены:
- **Динамический массив** (`dyn_arr.hpp`, `dyn_arr.cpp`) — собственная реализация динамически расширяемого массива.
- **Связный список** (`list.hpp`, `listtest.cpp`) — реализация списка с набором тестов для проверки корректности.
- **Стек** (`stack.hpp`, `stacktest.cpp`) — реализация стека с набором тестов.
- **Дерево** (`tree.hpp`) — базовая реализация древовидной структуры данных(в разработке).
- **Алгоритмы сортировки** (`mysorts.hpp`) — коллекция алгоритмов сортировки(сортировка шелла, сортировка пузырьком, сортировка простым выбором(рекурсивная и итеративная реализация), сортировка разбиением по схеме Ломуто, сортировка по опорному элементу, сортировка слиянием).
- **Рекурсия** (`recursion.cpp`, `rec.cpp`, `recursion.txt`) — примеры рекурсивных алгоритмов и текстовые пояснения к ним.
